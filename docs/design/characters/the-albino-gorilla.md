# The Albino Gorilla
**Data:** `the-albino-gorilla.ts` · CORE · FOLKLORE/BEAST/BRUISER · 170 HP

## Identity / win condition
Enormous, quiet strength. **Silverback Slam** is 40 for Might 2; Ground Pound is 20 to every enemy; Chest Beat frightens every enemy for 2 turns; Banana Break heals 20.

## Counterplay
Everything costs Might, so **Frost Jotunn**'s lock stops nearly all of it. The 40 is a 2-turn cooldown; Fear has no engine rule, so Chest Beat is mostly flavour (OQ-86).

## Readability
Four abilities, four numbers.

## Deviations
Reworked once so it did not overlap **Anubian Judge**: Chest Beat is Fear rather than Weakness. Tested in `packages/engine/src/scenarios/region8.scenario.test.ts`.
